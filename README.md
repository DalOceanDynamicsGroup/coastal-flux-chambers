## Data Acquisition

Raw Eosense and Pro-Oceanus data are collected using Python-based data acquisition scripts maintained at:
https://github.com/racheel/FluxChamber

This repository contains documentation related to flux chamber development, along with analysis and results derived from the resulting data.

## Repository Structure

- `code/` - Reusable MATLAB functions and methods
- `analysis/` - Analysis scripts and workflows
- `plotting/` - Scripts for figure generation
- `external/` - Scripts for other sources
- `data/` - Processed datasets (raw data excluded)
- `docs/` - Project documentation and theory
